# Report Sections

Use this section order for compact sourced reports:

1. 首页摘要
2. 面试官问题与我的回答
3. 重点追问复盘
4. 代码题复盘
5. 高风险技术点速记
6. 参考来源
7. 后续巩固资料

Do not add `7天训练计划` or `证据与转写说明` unless the user explicitly asks for a long coaching report.

`后续巩固资料` should contain 5-8 short, traceable resources selected from the interview's actual weak topics. It is not a training plan and should not become a long course-note section.

Privacy default: final PDFs and `references.md` should not expose local absolute paths. Use event ids, artifact ids, basenames, and time ranges for local evidence unless the user explicitly asks for a debug/provenance bundle.

Do not add a raw transcript section unless the user explicitly asks for it.
